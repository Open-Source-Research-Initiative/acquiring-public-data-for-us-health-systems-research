# Contributor screening

Start with the [screening tracker, issue #5](https://github.com/Open-Source-Research-Initiative/acquiring-public-data-for-us-health-systems-research/issues/5). All nine issues are open to contributors and labelled `help wanted`. Choose a batch, comment with the candidate IDs you intend to check, and contribute a PR or a source-linked issue comment. You can review an AI draft without installing candidate software.

The first round rechecks 33 historical leads under a [fixed contract](2026-11-17/CONTRACT.md). Separate model reviewers check the evidence; the coordinator retains disagreements and prepares one packet for Cole Lyons’s final PI review and sign-off. Model work is provisional. Routine screening needs no intermediate human approval.
