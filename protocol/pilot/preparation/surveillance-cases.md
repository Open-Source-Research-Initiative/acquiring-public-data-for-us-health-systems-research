## Assessment design, separate from execution

Actual oracle **not prepared** and no access controls or human assessment staff established. The examples printed in source docs are illustrations, not the independent expected answers. Before any future authorized execution, an independent custodian should derive publisher-specific request equivalence and content/semantic references, freeze and seal them independently of the executor, and arrange second-human review. If source response or metadata is unavailable, retain an unassessable or blocked outcome; a project README or client output is not an independent reference.

For COVIDcast, the original example specifies historical event dates but omits `as_of`; [revision-matched source](https://github.com/cmu-delphi/covidcast/blob/9f16cfc0c0975a978c4d53ed2e092ee089550b81/Python-packages/covidcast-py/docs/getting_started.rst) says latest issue is returned and historical values can be revised. An independent evaluator should document the [V4 endpoint](https://cmu-delphi.github.io/delphi-epidata/api/covidcast.html) parameters, response schema, geography and issue date, available data-use conditions, and result limits before a potential bracketed capture; a 2020 observation date is not a source version. The [fb-survey publisher documentation](https://cmu-delphi.github.io/delphi-epidata/api/covidcast-signals/fb-survey) describes aggregate survey measures and revisions; it is not proof the selected query is currently obtainable. V4 is being phased out per [publisher](https://cmu-delphi.github.io/delphi-epidata/); retain observed unavailability without migrating the candidate.

For EPHTrackR, [get_data source](https://github.com/CDCgov/EPHTrackR/blob/6893d31c60a76dec366b92d1c11c5c8a1f9b15fd/R/get_data.R) shows it derives temporal/geography/stratification requests then POSTs to Tracking `v1/getCoreHolder`. An independent assessment requires the exact independently constructed request and metadata from [CDC API help](https://ephtracking.cdc.gov/apihelp), measure definitions, stratification/geography/time identity and suppression rules. No exact independently checked request or oracle yet exists. Capture current-as-of results around any later attempt where terms and rate limits permit, retaining timestamps, redacted HTTP response metadata, defined-layer hashes and comparator rules. Same dated observation does not imply immutable release; payload access requires technical qualification, source-access checks and packet lock. Both current-snapshot checks remain contingent on source access, matching requests and input visibility; independently acquired reference proves neither publisher truth nor downstream fitness. Bracketing matches do not prove there was no intervening update. Suppressed, absent, empty and zero must remain distinct. Do not infer historical maintenance performance from these one-time cases.
