# Sealed assessment packet — template

**Keep inaccessible to executor until the primary output and log are locked.** The custodian must implement access control outside this file and record any disclosure. Expected records and values belong here, never in the execution packet.

- Case ID; assessor/custodian; independently auditing human and roles; freeze timestamp:
- Source publisher URL, release or snapshot window, query, observation time, provenance, access and retention terms:
- Source dictionary/version, content and identity evidence; hash and what it proves:
- Preselected records, expected values, missingness and scope; independent derivation and evidence location:
- Full-release completeness oracle or explicit bounded-extract limitation:
- Predeclared comparison, key/grain, ordering, canonicalization and tolerance; source-drift handling:
- Independently prepared checker, known-matching and altered fixtures, test evidence and limitations:
- Sealed location and access record; output/log lock time; unsealing time and recipient:
- Acquisition disposition and reason; fidelity/reproduction applicability and separate results; disagreement and review:
- Contamination, uncertainty, source limitations and retained evidence:

A source concordance check does not establish source truth. A same-input reproduction claim requires a comparable retained author/reference output; a fixture alone supports bounded fidelity only. A second qualified human audits the reference and outcome before any independent-review claim.
