# Execution packet — template

**Primary attempt only. Do not include expected values, reference-selected records, assessment fixtures, checker output or feedback.** Provide only materials an ordinary user is permitted to use. Freeze and date before execution; keep sealed assessment packet inaccessible to executor.

- Case/system/workflow IDs; software tag and commit/digest; selection cutoff and rule:
- Native documented task and full-release or bounded-query scope:
- Source, permitted endpoint, selected release or current-snapshot window, parameters:
- Revision-matched public documentation URLs and permitted configuration:
- Runtime profile, safety and access constraints, time/compute/network/spending limits:
- Executor identity, model/version, allowed tools and human supervisor:
- Allowed retry and stop conditions; logging and output lock location:
- Assumptions or known documentation mismatch:
- Frozen by and timestamp; authorized execution status:

After execution, retain commands, timestamps, exit status, outputs and intervention log without assessment feedback. Lock the primary output and log before unsealing assessment. Any reference-derived guidance constitutes separately recorded assistance and invalidates a claim of unassisted packet separation.
